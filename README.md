# 📱 Telegram Chat Viewer

A lightweight, client-side web application to beautifully render and view exported Telegram chat history (`JSON` or `HTML` formats). Stop digging through ugly files—load your export and read your conversations in a clean, responsive interface that mimics native chat clients.

## 🚀 Features

- **Local & Secure:** 100% client-side rendering. Your data never leaves your machine—no servers, no backend logs, completely private.
- **Clean UI:** Responsive design inspired by modern chat applications with clear message bubbles, timestamps, and sender identification.
- **Media Support:** Native handling of embedded media formats shared within chats.
- **Zero Configuration:** Just open the file and load your chat data. No complex installation or build steps required.

## 🛠️ Built With

* **HTML5** - Document structure and layout.
* **CSS3** - Custom chat bubble styling, responsive layouts, and modern typography.
* **JavaScript (Vanilla)** - Client-side file parsing and dynamic DOM rendering.

## 📦 Getting Started

Since this project runs entirely in the browser, setting it up is quick and straightforward.

### Prerequisites

You only need a modern web browser (such as Chrome, Firefox, Edge, or Safari) and an exported chat file from Telegram.

### How to Export Telegram Chats
1. Open **Telegram Desktop**.
2. Go to the desired chat or group.
3. Click on the three dots (top right corner) and select **Export chat history**.
4. Choose **JSON** (preferred) or **HTML** format and click Export.
